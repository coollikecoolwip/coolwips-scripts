## Attribution checklist

For third-party or modified scripts, document:

1. Original author/handle (link to their official profile if verified).
2. Canonical original source (not just a mirror or repost).
3. License or explicit redistribution permission; if unknown, mark it unknown and resolve before redistributing further.
4. Changes made here and, if applicable, the version or date of the upstream source.
5. Required dependencies and any remotely downloaded code.

**No global license has been added**, because that could misleadingly appear to grant rights over third-party code. Each author's applicable rights and license remain their own.

To report an incorrect attribution or request a credit correction, [open an issue](https://github.com/coollikecoolwip/coolwips-scripts/issues).
